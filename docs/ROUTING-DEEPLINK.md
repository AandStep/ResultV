# Ссылка на профиль маршрутизации для ResultV

Документ для панелей и провайдеров. Описывает, что нужно отдать, чтобы кнопка
«Импорт профиля» в ResultV завела вашу маршрутизацию.

Если вы уже публикуете такие ссылки для других клиентов — **менять формат не
нужно**. Полезная нагрузка та же самая, отличается только схема. Достаточно
добавить `resultv` в список клиентов рядом с теми, что уже есть.

## Как это работает

Обычная https-ссылка отвечает `302` и уводит на схему клиента:

```
GET https://panel.example/routing/resultv/whitelist

HTTP/1.1 302 Found
Location: resultv://routing/onadd/<base64url(JSON)>
Cache-Control: no-store
```

ResultV зарегистрирован в системе на схему `resultv://`, поэтому браузер
открывает приложение и передаёт ссылку ему. Приложение показывает, что в
профиле, и ждёт подтверждения пользователя — молча ничего не применяется.

## Полезная нагрузка

`base64url` (можно без выравнивающих `=`) от JSON в UTF-8. Шифровать не нужно:
профиль — это открытый список того, что куда идёт.

```json
{
  "Name": "impVPN Routing Whitelist",
  "RouteOrder": "block-proxy-direct",
  "DomainStrategy": "IPIfNonMatch",
  "Geoipurl": "https://panel.example/downloads/routing/202609010835/geo/geoip.dat",
  "Geositeurl": "https://panel.example/downloads/routing/202609010835/geo/geosite.dat",
  "LastUpdated": "1788322632",
  "DirectSites": ["geosite:private", "geosite:whitelist"],
  "DirectIp":    ["geoip:private", "geoip:whitelist"],
  "ProxySites":  [],
  "ProxyIp":     [],
  "BlockSites":  ["geosite:win-spy", "geosite:torrent", "geosite:category-ads"],
  "BlockIp":     []
}
```

### Поля

| Поле | Обязательно | Что это |
|---|---|---|
| `Name` | нет | Название профиля. Оно же — опознавательный признак: при повторном открытии ссылки профиль с тем же `Name` **обновляется**, а не заводится второй. Держите его стабильным между публикациями. |
| `DirectSites` / `DirectIp` | хотя бы один список непустой | Идёт напрямую, мимо туннеля |
| `ProxySites` / `ProxyIp` | — | Идёт через прокси |
| `BlockSites` / `BlockIp` | — | Блокируется |
| `RouteOrder` | нет | Порядок разбора правил. Допустимы все шесть перестановок `block`/`proxy`/`direct` через дефис. Неизвестное значение игнорируется. |
| `DomainStrategy` | нет | Как в xray: `IPIfNonMatch`, `AsIs`, `IPOnDemand` |
| `Geoipurl` / `Geositeurl` | нужны, если в правилах есть `geoip:` / `geosite:` | Прямые ссылки на `.dat`. Только `http(s)`. |
| `LastUpdated` | нет | Unix-время сборки правил, строкой |

Лишние поля не мешают: всё, чего нет в таблице, читается и пропускается. В
частности `GlobalProxy`, `UseChunkFiles`, `FakeDNS`, `DnsHosts`, `RemoteDns`,
`DomesticDns` и родственные им — ResultV их сейчас не применяет.

### Токены правил

Понимаются формы xray:

- `geosite:<категория>` — категория из вашего `geosite.dat`
- `geoip:<категория>` — категория из вашего `geoip.dat`
- `domain:example.com` — хост и его поддомены
- `full:example.com` — только этот хост, без поддоменов
- `10.0.0.0/8`, `8.8.8.8` — подсеть или адрес
- `example.com` — голый хост, читается как `domain:`

**Не поддерживаются** и будут показаны пользователю как непринятые:
`regexp:`, `keyword:`, `ext:`, `geosite:cat@attribute`, отрицания `geoip:!ru`.
Причина одна: движок ResultV (sing-box) таких правил не выражает, а тихо
подменять их на приблизительные значило бы возить трафик не туда, куда вы
написали.

То же касается категории `geoip` с `inverse_match` — «всё, кроме этих». Она не
загружается: импортировать перечисленные в ней префиксы означало бы ровно
обратный смысл.

## Geo-файлы

Формат — обычный v2ray/xray `.dat` (protobuf `GeoSiteList` / `GeoIPList`).
Ничего специального готовить не надо, подойдут те же файлы, что вы отдаёте
другим клиентам.

Чанковые файлы (`UseChunkFiles`) не нужны: ResultV читает `.dat` целиком.

## Ограничения

- не больше 20 000 правил на профиль суммарно;
- длина одного токена — до 512 символов;
- название — до 200 символов;
- размер base64 в ссылке — до 4 МиБ.

Всё, что за границей, отклоняется целиком с сообщением, а не обрезается молча.

## Проверка

Ссылку можно проверить, не поднимая ничего у себя: откройте её в браузере на
машине с установленным ResultV. Приложение поднимется, покажет разбор профиля
и попросит подтверждение. Если что-то в правилах не принято, оно перечислит
что именно и почему.
